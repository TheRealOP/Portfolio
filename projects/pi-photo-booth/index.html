Raspberry Pi Photo Booth Application

Raspberry PiEmbedded SystemsPythonBluetoothBLEWeb BluetoothLinuxsystemd

Engineered a comprehensive Raspberry Pi-based photo booth application, addressing embedded systems constraints while integrating camera hardware with Python services for image capture, collage generation, and session management. Implemented a dual-path printing flow with a Web Bluetooth kiosk interface for Instax Mini Link 3 printers plus a native BLE workflow using the bleak library for production reliability. Strengthened the experience with thorough error handling, fault tolerance, and systemd autostart for unattended public deployment, demonstrating full-stack expertise across embedded Linux, Bluetooth protocols, and scalable application architecture.
